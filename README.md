## 📌 نبذة عن المشروع

**Ezoo Download** برنامج لنظامي ويندوز وmacOS كُتب من الصفر بلغة **Rust**، يجلب الملفات من الروابط التي يحددها المستخدم ويحفظها على جهازه.
يقسّم البرنامج الملف على عدة اتصالات، ويستأنف العمل من حيث توقف إذا انقطع الاتصال. وتدعم واجهته **ثماني لغات**: العربية والإنجليزية والفرنسية والإسبانية والألمانية والبرتغالية والتركية والروسية.

> [!IMPORTANT]
> يتحمّل المستخدم مسؤولية احترام حقوق الملكية وشروط استخدام أي محتوى يتعامل معه من خلال البرنامج.

## 📦 التثبيت

### Windows

ثبّت البرنامج من **GitHub Releases** في صفحة المشروع.
يُثبَّت البرنامج للمستخدم الحالي ولا يحتاج إلى صلاحيات المسؤول.

### البناء من الشيفرة المصدرية على Windows

شغّل الملف **`BUILD.bat`**، وستجد ملف الإعداد `EzooDownload-Setup` في مجلد **`dist`**.

### macOS (Apple Silicon وIntel)

عند توفر بناء macOS في **GitHub Releases**، اختر `EzooDownload-macos-arm64.dmg` لأجهزة Apple Silicon (M1 وما بعده)، أو `EzooDownload-macos-x86_64.dmg` لأجهزة Intel. افتح ملف DMG واسحب **Ezoo Download.app** إلى اختصار **Applications** داخل النافذة، ثم أخرج القرص وشغّل التطبيق من مجلد **Applications**.

تتوفر أيضًا نسخة ZIP بالاسم نفسه وامتداد `.zip`. فك الضغط وانقل **Ezoo Download.app** إلى **Applications** أو **~/Applications**. لكل ملف DMG أو ZIP ملف `.sha256` للتحقق من سلامة التنزيل.

تنزيل الملفات العادية لا يحتاج إلى أدوات إضافية. للفيديو والصوت والتورنت، ثبّت الأدوات عبر [Homebrew](https://brew.sh):

```sh
brew install yt-dlp ffmpeg aria2
```

يجد البرنامج أدوات Homebrew في `/opt/homebrew/bin` و`/usr/local/bin` حتى عند تشغيله من Finder. تُحدَّث هذه الأدوات باستخدام `brew upgrade yt-dlp ffmpeg aria2`؛ لا يحدّثها البرنامج بنفسه على macOS.

#### البناء على Mac

ثبّت [Rust stable](https://rustup.rs) وأدوات Apple Command Line Tools (`xcode-select --install`) و**Python 3.10 أو أحدث**، ثم شغّل من مجلد المشروع. تنشئ أداة تغليف DMG تلقائيًا بيئة Python معزولة في `build-cache` وتثبّت الحزم بالإصدارات المحددة في `packaging/dmg-requirements.txt`. تُستخدم Python وهذه الحزم أثناء البناء فقط، ولا تُضمَّن في التطبيق أو ملف DMG:

```sh
./build-macos.sh
```

ينتج البناء تطبيقًا في `dist/macos-arm64/Ezoo Download.app` أو `dist/macos-x86_64/Ezoo Download.app` حسب الجهاز، بالإضافة إلى ملفي DMG وZIP وبصمة SHA-256 لكل منهما في `dist`. يتضمن DMG اختصار **Applications** للتثبيت بالسحب والإفلات. الحد الأدنى الافتراضي للبناء هو macOS 11؛ يمكن تغييره عبر `MACOSX_DEPLOYMENT_TARGET`. يبني GitHub Actions النسختين ويحتفظ بحزم DMG وZIP وبصماتها كملفات Artifact، ويضيفها إلى الإصدار عند نشر إصدار Windows المعتاد برسالة commit تحتوي `[release]`.

للبناء لهندسة محددة، أضف هدف Rust المناسب أولًا:

```sh
rustup target add aarch64-apple-darwin
./build-macos.sh --target aarch64-apple-darwin
# لأجهزة Intel: استخدم x86_64-apple-darwin بدلًا من aarch64-apple-darwin.
```

للتطوير يمكن استخدام `./build-macos.sh --debug`. ولتغليف ملف تنفيذي بُني مسبقًا، أضف `--skip-build` مع نفس اختيار الهدف و`--debug` إن استُخدم عند البناء.

#### ملاحظات macOS

- البناء الحالي يحمل توقيعًا محليًا (ad-hoc)، وليس توقيع Apple Developer ID أو توثيق notarization. إذا منع Gatekeeper نسخة نزلتها من مصدر تثق به، استخدم **System Settings → Privacy & Security → Open Anyway** ثم أكّد الفتح.
- تحديث التطبيق على macOS يدوي؛ **Help → Check for updates** يفتح صفحة الإصدارات. لا يُشغّل مثبّت Windows على Mac.
- البناء الافتراضي يستخدم وضع **Release** المحسّن ويعمل مباشرة على المعالج المختار؛ نسخة `arm64` لأجهزة Apple Silicon لا تحتاج إلى Rosetta أو Wine. يُتحقَّق من المعمارية والتوقيع المحلي عند التغليف.
- تُحمى كلمات المرور وملفات تعريف الارتباط المحفوظة على Mac بتشفير AES-256-GCM ومفتاح خاص بالتطبيق داخل **login Keychain**. تُقرأ البيانات القديمة وتُحمى عند الحفظ التالي. إذا تعذّر فتح Keychain أو فك التشفير، لا يستبدل البرنامج الملفات المحفوظة ببيانات فارغة؛ افتح Keychain وأعد المحاولة.
- بيانات اعتماد التنزيلات القديمة التي لا تحدد مصدرها لا تُرسل تلقائيًا عند الاستئناف؛ أعد إدخالها عند الحاجة. تبقى بيانات **Site Logins** المطابقة للموقع متاحة. لا تُعاد مشاركة الكوكيز أو كلمات المرور مع مصدر مختلف عند التحويل أو تنزيل أجزاء الفيديو.
- مراقبة الحافظة معطّلة افتراضيًا على macOS، ولا يقرأ البرنامج الحافظة عندما يكون الخيار معطّلًا. تُعلَّم الملفات المكتملة بصفة الحجر **quarantine** لتبقى معلومات مصدر الإنترنت متاحة لنظام macOS.
- لا توجد أيقونة في شريط القوائم حاليًا؛ إغلاق النافذة الرئيسية يخرج من التطبيق. التشغيل عند تسجيل الدخول خيار يدوي من الإعدادات ويستخدم LaunchAgent، ويُظهر النافذة الرئيسية. انقل التطبيق إلى مكانه الدائم في **Applications** قبل تفعيل هذا الخيار؛ إذا نقلته لاحقًا، أوقف الخيار وأعد تفعيله لحفظ المسار الجديد.
- إضافة المتصفح تعمل مع Chrome وEdge وFirefox وOpera وBrave على Mac. استخدم نافذة إضافة المتصفح داخل التطبيق؛ ملفات الإضافة موجودة داخل حزمة التطبيق. Safari غير مدعوم.
- يدعم macOS السكون وإيقاف التشغيل عند اكتمال التنزيلات؛ قد يطلب إيقاف التشغيل إذن **Automation** أو تأكيد إغلاق تطبيقات أخرى. الإسبات والإغلاق الإجباري للتطبيقات الأخرى غير مدعومين.
- ميزات Windows الخاصة بشفافية النافذة وشريط تقدم زر شريط المهام وسحب الملفات من التطبيق إلى تطبيق آخر غير مدعومة على macOS حاليًا.

## 🔍 سلوك البرنامج واتصالاته

حرصًا على الوضوح، هذه هي المهام التي يؤديها البرنامج تلقائيًا:

| الوظيفة | التفاصيل |
|---|---|
| 🔄 **تحديث البرنامج** | على Windows، عند التشغيل وكل 6 ساعات يقرأ البرنامج ملف `version.json` من GitHub Releases الخاصة بالمشروع. إذا وُجد إصدار جديد، يجلبه من GitHub Releases فقط، ويتحقق من بصمة SHA-256 الخاصة به، ثم يثبّته دون إظهار نوافذ ويعيد تشغيل نفسه. التحديث إلزامي، ويمكن البحث عنه فورًا من قائمة Help ← Check for updates. على macOS، يُحدَّث التطبيق يدويًا من صفحة الإصدارات. |
| 🧰 **الأدوات المساعدة** | على Windows، يستخدم البرنامج yt-dlp وFFmpeg وaria2 من مجلد `tools` ويحدّث الأدوات المدعومة من صفحات إصداراتها على GitHub. على macOS، ثبّتها وحدّثها عبر Homebrew. |
| 🔌 **الاتصال بالإضافة** | يفتح البرنامج منفذًا محليًا على `127.0.0.1` (الافتراضي 9614) لتتواصل معه إضافة المتصفح. يرفض أصول صفحات الويب وطلبات CORS التمهيدية ويقيّد اسم المضيف، لكنه ليس نظام اقتران أو مصادقة لعملية محلية محددة. طلبات البحث القادمة من الإضافة لا تستعير جلسة تسجيل دخول مخزّنة من طلب آخر. |
| 🍪 **ملفات تعريف الارتباط** | ترسل الإضافة إلى البرنامج ملفات تعريف الارتباط وعنوان الصفحة الخاصين بالملف المطلوب فقط، لكي تعمل الروابط التي تتطلب تسجيل الدخول. تنتقل هذه البيانات إلى البرنامج على الجهاز نفسه فقط. |
| 📋 **الحافظة** | عند تفعيل المراقبة، يعرض البرنامج إضافة روابط الملفات المنسوخة. إيقاف الخيار يوقف قراءة الحافظة؛ وهو معطّل افتراضيًا على macOS. |
| 🚀 **التشغيل عند تسجيل الدخول** | على Windows، خيار اختياري أثناء التثبيت ويمكن تغييره من الإعدادات. على macOS، يُفعّل صراحة من الإعدادات عبر `~/Library/LaunchAgents/com.ezoo.EzooDownload.plist`. |
| 💾 **البيانات** | تُحفظ الإعدادات وقائمة الملفات في `%APPDATA%\Ezoo\EzooDownload\data` على Windows، وفي `~/Library/Application Support/com.Ezoo.EzooDownload` على macOS. تُحمى حقول كلمات المرور وملفات تعريف الارتباط بـDPAPI على Windows، وبـAES-256-GCM ومفتاح داخل Keychain على macOS؛ وتُنشأ ملفات JSON والكوكيز المؤقتة بصلاحيات خاصة على Unix. تظل الروابط وأسماء الملفات نصًا عاديًا، وقد تتضمن الروابط رموز وصول. تصدير قوائم EF2 اختياري وقد يضم كوكيز نصية؛ لا تشاركها إذا احتوت بيانات خاصة. |

البرنامج **لا يجمع ولا يرسل** أي بيانات استخدام أو إحصاءات إلى أي جهة.
