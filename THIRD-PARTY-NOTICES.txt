Ezoo Download uses the following open source components.

Slint (user interface toolkit) - https://slint.dev
  Used under the Slint Royalty-free Desktop, Mobile, and Web Applications License 2.0.

yt-dlp - https://github.com/yt-dlp/yt-dlp
  The Unlicense (public domain). Its folder build (yt-dlp_win.zip) is fetched
  unchanged from its releases; it carries Python and the libraries yt-dlp's
  makers list in its own files.

QuickJS-NG - https://github.com/quickjs-ng/quickjs
  MIT License. qjs.exe is fetched unchanged from its releases, only when a
  video needs it (yt-dlp runs YouTube's player script with it).

FFmpeg - https://github.com/FFmpeg/FFmpeg
  The ffmpeg program in the "tools" folder is Ezoo Download's own small build
  of the unmodified FFmpeg sources (version in ffmpeg-version.txt), made with
  tools/ffmpeg/build.sh from the Ezoo Download sources. It is licensed under
  the GNU Lesser General Public License version 3 or later (see
  ffmpeg-LICENSE.txt in the "tools" folder).

LAME - https://lame.sourceforge.io
  Built into that ffmpeg program to make MP3 files. GNU Lesser General Public
  License (see lame-COPYING.txt in the "tools" folder).

OpenH264 - https://github.com/cisco/openh264
  Built into that ffmpeg program for the exact cut of "Download a part of a
  video" (the picture of the part is made again). BSD 2-Clause License (see
  openh264-LICENSE.txt in the "tools" folder).

Only in the build for Windows 7 / 8 / 8.1 (EzooDownload-Legacy-Setup.exe):

Python - https://www.python.org
  The "tools\python" folder: Python's embeddable package for 32-bit Windows,
  built from python.org's sources for Windows 7 and newer by
  https://github.com/adang1345/PythonVista. Python Software Foundation
  License (LICENSE.txt in that folder). It runs yt-dlp's Python build
  ("tools\yt-dlp.pyz", from yt-dlp's releases, Unlicense; see yt-dlp above).

Microsoft's Universal C Runtime (ucrtbase.dll and the api-ms-win-*.dll next
  to it in "tools\python"): Microsoft's signed files, unchanged, deployed
  next to the program that needs them as Microsoft documents for Windows 7 /
  8 / 8.1 ("app-local deployment"), taken from Microsoft's PowerShell 7.0.13
  for 32-bit Windows. Licensed by Microsoft for redistribution with programs.

yt-dlp's helpers, unchanged, in "tools\python\Lib\site-packages" (each with
its licence in its .dist-info folder): brotli (MIT), certifi (MPL-2.0),
charset-normalizer (MIT), idna (BSD-3-Clause), mutagen (GPL-2.0-or-later),
pycryptodomex (BSD-2-Clause / public domain), requests (Apache-2.0), urllib3
(MIT), websockets (BSD-3-Clause), yt-dlp-ejs (Unlicense, with MIT and ISC
parts).

rustls, webpki-roots - https://github.com/rustls
  The program's own TLS on Windows 7 / 8 / 8.1. Apache-2.0 / ISC / MIT;
  webpki-roots carries Mozilla's root certificates (CDLA-Permissive-2.0).

librqbit - https://github.com/ikatson/rqbit
  The torrent library built into the program (sharing, magnet links, DHT).
  Apache License 2.0.

Rust crates (tokio, reqwest, serde, chrono, tiny_http, arboard, rfd, tray-icon,
regex, sha2, aes, cbc, url, directories, filetime, ring, native-tls,
tokio-native-tls and their dependencies)
  MIT, Apache-2.0 and/or ISC licenses.
